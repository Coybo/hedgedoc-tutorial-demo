# HedgeDoc & Markdown Portfolio Tutorial

**Learn to build professional technical portfolios using HedgeDoc and Markdown**

This repository contains everything you need to create a standout portfolio for your cybersecurity and IT career. Follow along with video tutorials, use provided templates, and see real examples of professional portfolio structure.

## 🚀 How to Use This Tutorial

### Option 1: Follow Along (Recommended for Beginners)

1. **Watch the videos** - Follow along as we build Chad Hackerman's portfolio from scratch
2. **Reference the guide** - Keep [`Introduction_to_HedgeDoc.md`](https://github.com/Coybo/hedgedoc-tutorial-demo/blob/main/Introduction_to_HedgeDoc.md) open while you work

## 🛠️ Getting Started with HedgeDoc

1. **Access HedgeDoc** through your institution's server
2. **Create a new note** and give it a meaningful name
3. **Watch the [video series]()** to learn the basics
4. **Reference the markdown guide** as you build
5. **Save your work** regularly (HedgeDoc auto-saves, but export backups!)

### Exporting Your Work

When you're ready to move from HedgeDoc to GitHub:

1. **Export as Markdown** from HedgeDoc (File → Export → Markdown)
2. **Create a GitHub repository** for your portfolio
3. **Upload your markdown files** maintaining the folder structure
4. **Add your images** to the `images/` folder
5. **Test all links** to make sure navigation works

## 📝 Tips for Success

**Start Simple**

- Don't try to build everything at once
- Begin with your resume basics
- Add one project at a time
- Grow your portfolio incrementally

**Be Consistent**

- Use the same formatting style throughout
- Keep bullet point styles uniform
- Maintain a logical heading hierarchy
- Proofread everything before publishing

**Show, Don't Just Tell**

- Include code samples from your projects
- Add screenshots and diagrams
- Link to live repositories
- Quantify your achievements with metrics

**Keep It Professional**

- Use proper grammar and spelling
- Write clear, concise descriptions
- Include meaningful commit messages
- Update your portfolio regularly
